{{/* --------------------------------------------------------------------- Typographic cover — a title card set from type, not a photograph. Every note gets one, so the archive reads as a run of issues rather than a list with some pictures missing. Nothing is fetched or generated at build time: the whole thing is inline SVG plus the page's own palette, so it is deterministic, editable from front matter, and weighs nothing. Called with: page the note number its archive number, already zero-padded (e.g. "004") Front matter it reads: cover_words one or two short core words. The whole design. cover_question an optional second line, set small. cover_variant split | stack | block. Omitted is fine — see below. Decorative by design: the row prints the real title immediately beside it, so the SVG is hidden from assistive tech rather than repeating it. --------------------------------------------------------------------- */}} {{- $page := .page -}} {{- $number := .number -}} {{- $words := $page.Params.cover_words -}} {{- $question := $page.Params.cover_question -}} {{/* No cover words is a valid state — a note written before the fields existed, or one where nothing short says it. It gets the branded fallback rather than an empty frame or a broken image. */}} {{- $isFallback := not $words -}} {{- if $isFallback -}} {{- $words = slice "FIELD" "NOTE" -}} {{- if not $question }}{{ $question = printf "NO. %s" $number }}{{ end -}} {{- end -}} {{- $words = first 2 $words -}} {{/* Variant, when unset, comes from a hash of the note's own URL: stable across builds and unaffected by anything being filed before it, which is what ordinal position would not survive. */}} {{- $variant := $page.Params.cover_variant -}} {{- if not $variant -}} {{- $variant = index (slice "split" "stack" "block") (mod (hash.FNV32a $page.RelPermalink) 3) -}} {{- end -}} {{- if $isFallback }}{{ $variant = "stack" }}{{ end -}} {{/* One size for both words, taken from the longer of the two, so a pair reads as a single object and can never run past the measure. 0.56em is a measured average advance for the condensed uppercase; the cap stops two- and three-letter words from swallowing the card. */}} {{- $longest := 1 -}} {{- range $words -}} {{- $n := strings.RuneCount . -}} {{- if gt $n $longest }}{{ $longest = $n }}{{ end -}} {{- end -}} {{- $size := math.Min 96 (div 268.0 (mul 0.56 $longest)) -}} {{- $lead := mul $size 0.78 -}}
