{{/* --------------------------------------------------------------------- Typographic cover — a small visual index for an archive row. Not a headline and not a miniature poster. The article title beside it is the headline; this is the thing your eye lands on between the note number and that title, and it has to stay quieter than both. Everything here is sized against that: the core words read at 210px wide but never approach the title's weight, and the note number is not repeated inside the card because the row already prints it. Called with: page the note number its archive number (used only to key the clip path) Front matter: cover_words one or two short core words cover_question optional tiny second line cover_variant split | rhythm Two compositions, deliberately: one paper-ground, one ink-ground, sharing a left block, a circle, a vertical rhythm and the same text column. A third would start turning the archive into a set of separate posters. Decorative: the row prints the real title alongside, so the whole SVG is hidden from assistive technology rather than repeating it. --------------------------------------------------------------------- */}} {{- $page := .page -}} {{- $number := .number -}} {{- $question := $page.Params.cover_question -}} {{- $words := $page.Params.cover_words -}} {{- if not $words -}} {{- $words = slice "FIELD" "NOTE" -}} {{- $question = "" -}} {{- end -}} {{- $words = first 2 $words -}} {{- $w1 := index $words 0 -}} {{- $w2 := "" -}} {{- if gt (len $words) 1 }}{{ $w2 = index $words 1 }}{{ end -}} {{- $variant := lower ($page.Params.cover_variant | default "") -}} {{- if not (in (slice "split" "rhythm") $variant) -}} {{/* Unset or legacy: hash the note's own URL, which is stable across builds and unaffected by anything filed before it. */}} {{- $variant = index (slice "split" "rhythm") (mod (hash.FNV32a $page.RelPermalink) 2) -}} {{- end -}} {{/* Geometry. The left block is a third of the card; the words share one column beside it. */}} {{- $tx := 82.0 -}} {{- $measure := 116.0 -}} {{/* A template cannot measure text, so each word is sized from its length against a measured advance for IBM Plex Sans Condensed 700 — the constants sit above the widest real cases at each length (NEW is 0.696em/char, MAKER 0.629, LANGUAGE 0.601). The ceilings are the design sizes; the division only ever pulls a long word down, so one long word can never shrink the rest of the archive. */}} {{- $sizes := slice -}} {{- range $i, $word := (slice $w1 $w2) -}} {{- $ceiling := cond (eq $i 0) 31.0 23.0 -}} {{- if $word -}} {{- $n := strings.RuneCount $word -}} {{- $adv := 0.61 -}} {{- if le $n 4 }}{{ $adv = 0.70 }}{{ else if le $n 6 }}{{ $adv = 0.64 }}{{ else if gt $n 9 }}{{ $adv = 0.63 }}{{ end -}} {{- $sizes = $sizes | append (math.Min $ceiling (div $measure (mul $n $adv))) -}} {{- else -}} {{- $sizes = $sizes | append $ceiling -}} {{- end -}} {{- end -}} {{- $s1 := index $sizes 0 -}} {{- $s2 := index $sizes 1 -}} {{- $uid := printf "fnc%s" $number -}}
